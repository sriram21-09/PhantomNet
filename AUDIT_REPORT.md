## 1. Executive Summary

This report delivers a forensic audit of every machine learning model, dataset, feature extraction pipeline, campaign clustering algorithm, backend integration, experimental benchmark, and published claim in the **PhantomNet** project.

### Summary of Audit Verdicts
1. **Machine Learning Metrics:** The reported 100.0% accuracy, precision, recall, and F1-score in `experiments/results/paper_metrics.json` are **mathematically invalid artifacts** of trivial synthetic class separability. Three features in `labeled_events_v2_enhanced.csv` possess zero class overlap due to a hardcoded data generation routine (`update_dataset.py`).
2. **Feature Leakage:** The 15-dimensional `FeatureExtractor` in `backend/ml/feature_extractor.py` ingests the model's own target (`threat_score`) and ground-truth label status (`is_malicious` as `malicious_flag_ratio`), causing **circular target and label leakage**.
3. **Statistical Claims & Experimental Fabrication:** The claimed $N=30$ repeated autonomous E2E pipeline runs in `experiments/run_dbscan_normalization_experiment.py` were **never executed**. The Fisher's Exact test ($p = 1.69 \times 10^{-17}$) was computed from a hardcoded contingency table `[[0, 30], [30, 0]]`. Furthermore, `publication_table.md` hardcodes $W=794.0$ while `statistical_tests.csv` records $W=817.5$.
4. **Runtime Semantic Mismatch:** In `backend/ml/threat_scoring_service.py`, runtime code extracts 15 network flow features, slices the first 12 (`feature_vector.iloc[:, :12]`), and feeds them into `AttackClassifier_Enhanced_v1.0.0.pkl`, which was trained on 12 host/command behavioral features. At runtime, packet event rates are interpreted as shell command counts, and destination port classes are interpreted as command lengths.
5. **DBSCAN Clustering Deficiencies:** In production code (`backend/ml_engine/campaign_clustering.py`), DBSCAN runs without `StandardScaler`. While applying `StandardScaler` prevents complete collapse (0 clusters, 100% noise), the standardized model yields 71.0% noise, an Adjusted Rand Index (ARI) of only 0.2116, and collapses separate SSH and Web attack campaigns into a single cluster.
6. **E2E Test Masking:** Integration tests (`tests/e2e/test_full_pipeline_e2e.py`) manually injected `attack_type = "SSH_AUTH_FAILURE"`, `is_malicious = True`, and `threat_score = 0.65` directly into the database, masking the failure of the autonomous detection pipeline.

## 3. Forensic Findings Categorized by Severity

### 3.1 CRITICAL SEVERITY

#### F-01: Trivial Synthetic Class Separability in `labeled_events_v2_enhanced.csv`
- **Location:** `backend/ml/update_dataset.py:L14-47`, `backend/ml/feature_engineering_v2.py:L76-120`
- **Evidence:** `update_dataset.py` generates 5,000 events where:
  - 100% of benign events have `raw_data = "GET /index.html HTTP/1.1"` and `event = "web_access"`.
  - 100% of malicious events are randomly sampled from 5 fixed exploit strings (`"cat /etc/passwd"`, `"../../etc/shadow"`, `"admin' OR '1'='1"`, `"rm -rf /"`, `"ls -la; id; whoami"`).
  - Consequently, in `labeled_events_v2_enhanced.csv`:
    - `avg_command_length`: Benign is strictly 24.0 ($\sigma=0$); Malicious ranges from 4.67 to 16.0.
    - `payload_entropy`: Benign is strictly 4.0535 ($\sigma=0$); Malicious ranges from 2.50 to 3.46.
    - `payload_to_cmd_ratio`: Benign is strictly 12.0 ($\sigma=0$); Malicious is 4.0 to 8.0.
- **Impact:** Any linear threshold or single decision split achieves 100.0% accuracy, precision, recall, and F1. The metrics in `experiments/results/paper_metrics.json` are artifacts of synthetic generation.

#### F-02: Circular Target and Ground-Truth Label Leakage in 15D Feature Extractor
- **Location:** `backend/ml/feature_extractor.py:L111-120`
- **Evidence:**
  ```python
  # Threat score (if available from previous stage or input)
  features["threat_score"] = float(event.get("threat_score", 0.0))

  # Malicious flag ratio
  features["malicious_flag_ratio"] = (
      sum(self.ip_malicious_flags[src_ip]) / len(self.ip_events[src_ip])
      if self.ip_events[src_ip]
      else 0.0
  )
  ```
- **Impact:** `threat_score` is the prediction output of the model, fed back as an input feature (circular leakage). `malicious_flag_ratio` computes the ratio of events where `is_malicious=True` (direct label leakage). In `data/training_dataset.csv`, benign rows have `threat_score=0.0` and `malicious_flag_ratio=0.0`, while malicious rows jump to `threat_score=0.6` and `malicious_flag_ratio>0`.

#### F-03: Fabricated Autonomous E2E Fisher's Exact Contingency Table
- **Location:** `experiments/run_dbscan_normalization_experiment.py:L1472-1479`, `experiments/results/dbscan_normalization/publication_table.md:L17`
- **Evidence:**
  ```python
  # 2. Categorical Autonomous E2E Success/Failure Test (N=30 repeated runs)
  contingency_table = [[0, 0], [30, 0]]
  odds_ratio, fisher_p = stats.fisher_exact([[0, 30], [30, 0]])
  ```
- **Impact:** The script never executed 30 autonomous E2E pipeline iterations. The $2 \times 2$ table `[[0, 30], [30, 0]]` was fabricated directly into `scipy.stats.fisher_exact`, yielding $p = 1.69 \times 10^{-17}$. In addition, line 1750 hardcodes `| **Autonomous E2E Completion** | 0.0% (0/30) | 100.0% (30/30) | +100.0% | Fisher's Exact $p < 0.001$ |` into markdown.

#### F-04: Defective Checkpoint `AttackClassifier_Enhanced_v1.0.0.pkl`
- **Location:** `ml_models/registry/AttackClassifier_Enhanced_v1.0.0.pkl`
- **Evidence:** When evaluated on `labeled_events_v2_enhanced.csv` (5,000 samples) in `run_publication_validation.py`:
  - `Accuracy: 0.6976`, `Precision: 0.0`, `Recall: 0.0`, `F1: 0.0`.
  - Confusion Matrix: `TN=3488, FP=0, FN=1512, TP=0`.
- **Impact:** The deployed model artifact classifies 100% of inputs as benign (label 0).

#### F-05: Discrepant Wilcoxon Statistic and Missing Raw Latency Arrays
- **Location:** `experiments/results/dbscan_normalization/publication_table.md:L16`, `experiments/results/dbscan_normalization/statistical_tests.csv:L2`
- **Evidence:**
  - `publication_table.md` reports: `Wilcoxon W=794.0, p < 0.001`.
  - `statistical_tests.csv` records: `Statistic: 817.5, p_value: 4.33e-09`.
  - The 100 raw float latency observations were never persisted to disk by the experiment script (an uncommitted script `raw_latency_arrays.py` was left untracked in root).

### 3.2 HIGH SEVERITY

#### F-06: Runtime Feature Space Semantic Alignment Mismatch
- **Location:** `backend/ml/threat_scoring_service.py:L148-168`
- **Evidence:**
  ```python
  features_dict = _FEATURE_EXTRACTOR.extract_features(event) # 15 network flow features
  ...
  X_input = feature_vector.iloc[:, :n_feat].values # Slices first 12 columns
  ```
- **Impact:** The model expects:
  `[command_count, avg_command_length, shell_escape_count, directory_traversal_count, failed_login_count, payload_entropy, interaction_interval_var, persistence_score, ua_diversity, lateral_movement_index, sensitive_file_count, payload_to_cmd_ratio]`.
  The runtime service supplies:
  `[packet_length, protocol_encoding, source_ip_event_rate, destination_port_class, threat_score, malicious_flag_ratio, attack_type_frequency, time_of_day_deviation, burst_rate, packet_size_variance, honeypot_interaction_count, session_duration_estimate]`.
  Network flow statistics are treated as shell command metrics.

#### F-07: Unscaled DBSCAN Production Failure & Standardized DBSCAN Poor Clustering
- **Location:** `backend/ml_engine/campaign_clustering.py:L80`, `experiments/results/dbscan_normalization/campaign_analysis.csv`
- **Evidence:**
  - Production `campaign_clustering.py` calls `self.model.fit_predict(df.values)` on unscaled features (`src_port`, `interval_variance`, `dst_port_class`, `entropy`). Port numbers (1024–65535) dominate Euclidean distance, forcing all samples into noise (`cluster=-1`, ARI=0.0000).
  - Even with `StandardScaler` applied (`run_dbscan_normalization_experiment.py`), DBSCAN produces **71.0% noise** and only recovers 2 clusters with an ARI of **0.2116** and Pairwise F1 of **0.0317**. Cluster 0 merges SSH brute force and Web SQLi attacks, while Cluster 1 contains benign traffic contamination.

#### F-08: Database State Tampering in Integration Tests
- **Location:** `tests/e2e/test_full_pipeline_e2e.py:L153-180`
- **Evidence:** In Stage 2b, the test manually executes:
  ```python
  for pid in inserted_ids:
      pkt = db.query(PacketLog).get(pid)
      if pkt:
          pkt.threat_score = max(0.55, result.score if result.score else 0.5)
          pkt.threat_level = "MEDIUM" if (result.score or 0) < 0.7 else "HIGH"
          pkt.attack_type = "SSH_AUTH_FAILURE"
          pkt.is_malicious = True
  db.commit()
  ```
- **Impact:** The pipeline cannot run autonomously from raw packet ingestion to playbook synthesis. The test forces downstream execution by overwriting database records.

#### F-09: Unvalidated Heuristic DBSCAN Hyperparameters
- **Location:** `backend/ml_engine/campaign_clustering.py:L26-30`
- **Evidence:** `eps = 0.5`, `min_samples = 5` are hardcoded without k-distance elbow estimation, density analysis, or sensitivity studies.

#### F-10: Runtime Code Defects and Exception Traps
- **Location:** `backend/ml/threat_scoring_service.py:L22`, `backend/ml_engine/explainability.py:L39-41`
- **Evidence:**
  - `threat_scoring_service.py` uses `os.getenv("REDIS_HOST", ...)` without importing `os` at the module level.
  - `explainability.py` checks `if model_components and "model" in model_components:`, raising `TypeError` when `load_model()` returns a `RandomForestClassifier` instance.
