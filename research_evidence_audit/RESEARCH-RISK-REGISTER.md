# PhantomNet Research Risk Register

| Risk ID | Category | Severity | Description | Evidence & Root Cause | Paper Implication | Remediation Required |
|---|---|---|---|---|---|---|
| RSK-01 | Dataset | CRITICAL | Trivial Synthetic Class Separability | 3 features have zero overlap between benign and malicious in labeled_events_v2_enhanced.csv. Single-feature thresholding achieves 100% accuracy. | Paper claims of 99.4% or 100% accuracy will be rejected by reviewers as synthetic data artifacts. | Generate realistic evaluation dataset with diverse benign traffic and varied payloads. |
| RSK-02 | Feature Alignment | HIGH | Semantic Feature Mismatch | Runtime feature_extractor.py produces 15 network flow features, but AttackClassifier_Enhanced_v1.0.0.pkl was trained on 12 host behavioral features. Bridged via raw array slicing iloc[:, :12]. | Runtime threat scores are computed on semantically mismatched feature vectors. | Retrain model on 15-dimensional network flow features or align runtime parser with behavioral extractor. |
| RSK-03 | Pipeline / SOAR | HIGH | DBSCAN Clustering Failure | Unscaled DBSCAN produces 0 clusters (100% noise) due to differing feature magnitudes (ports vs intervals). Autonomous E2E pipeline fails to generate playbooks. | Claims of autonomous closed-loop SOAR response fail in end-to-end execution. | Deploy StandardScaler prior to DBSCAN in production pipeline (proven to yield 2 clusters and 100% E2E completion). |
| RSK-04 | ML Architecture | HIGH | LSTM Attack Sequence Predictor Unimplemented | backend/ml/lstm_attack_predictor.py contains placeholder fallback logic; no PyTorch or TensorFlow model weights exist. | Reviewers will flag paper claims of deep learning attack sequence prediction as unsupported. | Remove deep learning claims or implement and train an actual LSTM model. |
| RSK-05 | Generalization | MEDIUM | No External Benchmark Validation | Evaluation conducted solely on project-internal synthetic data; no evaluation on CIC-IDS2017, UNSW-NB15, or NSL-KDD. | Limits academic credibility and prevents comparative baseline positioning against prior art. | Evaluate PhantomNet feature pipeline and classifiers against public benchmark datasets. |
| RSK-06 | Security | MEDIUM | Checked-in Secrets & Default Keys | .env file present in repository containing default credentials and JWT secret tokens. | Security audit failure; violates secure software engineering standards. | Add .env to .gitignore, provide .env.example, and enforce environment-provided secret keys. |
| RSK-07 | LLM Engine | MEDIUM | LLM Threat Narratives Untested | LLM narrative generation is disabled by default, falls back to static Jinja2 template, and lacks quantitative BLEU/ROUGE evaluation. | Paper claims of LLM orchestration cannot be substantiated with empirical performance data. | Scope paper to template-based playbook generation or conduct controlled evaluation of LLM narrative accuracy. |
| RSK-08 | Concurrency | LOW | SQLite Under High Volume | Concurrent writes from multi-protocol honeypots may saturate SQLite lock under extreme burst traffic. | Potential event drop during high-volume distributed attack simulations. | Ensure SQLite WAL mode (PRAGMA journal_mode=WAL) and busy timeouts are consistently configured. |
